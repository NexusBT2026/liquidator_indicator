## What Was Fixed

### Fix #1: Pandas 2.x Timestamps

**Problem:**  
Pandas 2.x changed default timestamp precision from nanoseconds to microseconds. The manual conversion assumed nanoseconds, breaking on pandas 2.x.

**Solution:**  
Use pandas' built-in `.timestamp()` method instead of manual conversion:

```python
# OLD (broke on pandas 2.x):
timestamps_seconds = (df['timestamp'].astype(np.int64).to_numpy() / 1e9).astype(np.float64)

# NEW (works on all pandas versions):
timestamps_seconds = df['timestamp'].apply(lambda x: x.timestamp()).to_numpy(dtype=np.float64)
```

### Fix #2: Clustering Snowball Bug

**Problem:**  
Comparing against a shifting mean caused narrow price ranges to collapse into one zone.

**Solution:**  
Compare against fixed cluster boundaries instead:

```python
# OLD (buggy):
if abs(p - cluster_mean) / cluster_mean <= pct_merge:

# NEW (fixed):
cluster_center = (cluster_price_max + cluster_price_min) / 2.0
max_allowed_distance = cluster_center * pct_merge
if abs(p - cluster_center) <= max_allowed_distance and \
   (price_range == 0 or abs(p - cluster_center) / cluster_center <= pct_merge):
```
